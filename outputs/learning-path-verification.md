# Ordered learning path change

The tutor now creates an ordered, topic-specific pathway when a solo or uploaded-notes session begins. The first step is the basic idea. Gemini proposes deeper subtopics in sequence; Lower Primary, High School, and Professional selections produce four, five, and six total steps respectively. The saved path and current position survive reload. The tutor prompt is limited to the current step and asks at most one focused question when an explanation is incomplete. A clear explanation advances to the next objective; the server supplies the transition message so an extra question about a completed step cannot be shown. After the final step, the session is marked completed and mastery reaches 100.

This change was built and checked in an isolated copy before integration. Self-assessment: **9/10**. Strengths: persistent ordered progress, level-specific depth, safe model-output validation, migration, focused step transitions, legacy-session fallback, UI progress display, and failure tests. Remaining limit: the model still judges whether an explanation is adequate, so educators should review its decisions during the pilot.

Verification on the integrated project: 62 tests across 10 files passed; lint, TypeScript, production build, and `git diff --check` passed. Tests cover pathway creation and level depth, weak-answer stay, good-answer advance, saved progress after reload, malformed outline rejection without a saved session, final completion without repeated questions, and client pathway display. A live Gemini test created a four-step Lower Primary Photosynthesis path and saved a real chat turn. The temporary account and session were removed after the test.
