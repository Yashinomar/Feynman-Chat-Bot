# Engineering reports

For every substantive change to this application, add a dated report in this folder or update that day's report. Include the problem, changes made, checks run and their results, remaining limits, and any setup or deployment action needed. Keep private keys, passwords, uploaded notes, and database records out of reports. Use the current project state when reporting; do not carry old test counts forward after new changes.
